# pillbox-skills

***Pillbox skills and extensions for AI coding assistants***

Part of the [Pillbox](https://github.com/Kevinsillo/pillbox) ecosystem.

</div>

Installed automatically via `pillbox skills install` — you probably don't need to clone this directly.

## What this is

The official Pillbox skill for AI coding assistants. Guides the agent to use Pillbox tools correctly — opening prescriptions, saving pills proactively, and retrieving context at the start of each session.

## Manual installation

```bash
pillbox skill install
```

Or copy the skill directory manually to your assistant's skills folder.

→ [pillbox](https://github.com/Kevinsillo/pillbox) — install the full ecosystem from there.
